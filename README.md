<h3>Повторение за аватаром на видео</h3>

Два человека соревнуются за точность повторения движения за аватаром.
Два человека встают в разные половины экрана и должны повторять движения с экрана. За каждое движение будет начисляться определённое кол-во баллов. Побеждает человек с наибольшим количеством баллов.
